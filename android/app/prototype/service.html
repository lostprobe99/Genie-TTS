API 接口与集成文档

RESTful v1
POST /api/tts
语音合成流
http://192.168.1.108:9880/api/tts
请求参数说明 (Query 或 JSON)
text 必填 string
合成文本 (UTF-8)
speaker 可选 string
角色 ID (默认 march_7th_v2)
speed 可选 float
语速 0.5 - 2.0 (默认 1.0)
pitch 可选 float
音调 0.5 - 1.5 (默认 1.0)
format 可选 string
wav / mp3 / pcm (默认 wav)
check 响应：状态码 200 OK，返回音频二进制流 (audio/wav)
GET /api/speakers
获取可用角色
http://192.168.1.108:9880/api/speakers

返回全部已就绪角色的名称、音色标签及模型哈希列表，格式为标准 JSON 数组。

# Android 正式应用

这条分支用来做正式应用。本文是功能设计和界面示意图。合成全部在手机上完成，文字、音素、韵律、声学模型和声码器都不出手机。只做中文。

工程在 `android/app`。给人看的版本遵循 [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html)，现在是 `0.0.12`。`0.y.z` 是初始开发，角色包和韵律包的格式到 `1.0.0` 才锁定。那之后，修订号加一是修问题，次版本号加一是加功能，旧包仍能用；主版本号加一是旧包不能继续用。`versionCode` 是 12，只给系统比较新旧，每次发布加一，不由这三位数字算出来。包名 `com.genie.tts`，和演示程序分开安装。韵律包这次没有改，下载地址仍是已经发出的 `app-0.0.3`。

安装包不带角色，也不带韵律模型。应用使用正式签名，只安装在 arm64 手机上。更新应用不会清掉已导入的角色和韵律包。

示意图里的 Genie 是顶栏上的应用名。`( 播放 )` 表示还不能点，`[ 播放 ]` 表示可以点。`#` 是抽屉拉开后变暗的主屏。

## 界面结构

四个页面从主屏进入。

- 主屏、角色管理、服务管理和韵律模型的左上角都是三横线。点它从左侧拉出抽屉，后面的页面变暗。点暗处或返回，抽屉收回。关于页左上角是返回，回到主屏。
- 抽屉里是四条，互相同级：角色管理、服务、韵律模型、关于。服务管理右边的胶囊在没开时是灰色的「未开启」，开着时是「运行中」。
- 选定当前角色只在主屏的下拉菜单里完成。

弹出层盖在当前页面上，不单独占一级页面：韵律告警、导入命名。

## 主屏

最上面是顶栏：左边三横线，中间应用名。

顶栏下面是角色。一个角色都没有时，这里只显示「未选择角色」，没有下拉菜单。已经导入过角色时，这里是下拉菜单，列出这些角色的名字，最后一项固定是「未选择角色」。选中最后一项，就回到没选角色的状态。

中间是多行文本框，可以打字，也可以粘贴。草稿留在手机上，下次打开还在。

文本框下面在点过合成之后出现句子列表。正在合成或正在播放的那一句标出来。合成完成的句子可以点，点了只重听这一句，不重新合成。

底栏是语速，然后是「合成」和「播放」。没有单独负责朗读的播放键，也没有分享。

语速默认 **1.00**，范围 0.60 到 1.40，一档 0.05。第一次安装是 1.00，之后记住上次的值。1.00 是模型自己的速度。小于 1 把语义帧拉开，声音变长，音高不变。大于 1 抽掉一些帧，声音变短。语速在合成时生效。播放不会重新套用语速。

合成可用的条件是：选中了一个角色，文本框不是空的，并且当前没有正在合成。选的是「未选择角色」时，合成不可用。

点合成后，合成键先变成「加载中」，旁边写「正在加载模型」。每一句开始时，合成键显示当前句数，旁边写「正在合成第 2 句，共 4 句」。完成后写出可播放的句数，每句下面写出时长。播放时这个键仍是停止，旁边的时间往前走。这句几乎没有声音，或者播放没有真正开始，都会写在这一行。

合成完成后如果改了正文、语速或角色，播放键再次不可用，需要重新合成。

主屏不铺调试日志。应用如果在合成中途退出，下次打开时主屏第一行写「上次合成没有完成」，并带上版本。某一句失败时，说明写在那一行下面。

## 朗读

正文按桌面端 `Utils/TextSplitter.py` 切开，界面上没有这项设置。

- 换行先去掉，换行不断句。
- 句号、问号、叹号、省略号收成一句。有效长度不到 5，就并进下一句。单独一个「好。」后面没有字，仍然留成一句。
- 逗号、顿号、分号、冒号平时不断。有效长度攒到 40，大约二十个字，再遇到这些才切开。
- 有效长度不计标点。一个汉字算 2，一个英文字母或数字算 1。

某一句得不到音素，就在那一行写「这句没有读出来」，继续合成后面的句子。

每一句合成完再进入播放，32 kHz，单声道。同一次合成里，声学模型只加载一次。有韵律模型时，参考句的韵律只算一次。换角色再合成，才重新加载声学模型，并清掉上一个角色的参考韵律。

这些没有设置项：

- 每一句送进模型前，句首加一个句号。它是开头的短暂停顿，避免第一句被吃掉，不会读成「句号」两个字。
- 温度 1.00、TopK 15、重复惩罚 1.35，直接用角色包里的原模型。
- 一句最多解码 500 步。模型自己停下就结束。
- 线程按手机核数自动取，一般是 4 到 6，界面上不显示。

## 角色管理

这一页只管理角色。没有从目录下载。顶栏左上角是三横线。批量管理时这一格变成关闭，用来退出批量。下面是已导入角色的卡片。每张卡有头像、名字、角色 id 和试听。长按弹出白底卡片，可以改名或删除。批量删除和清空角色列表也用这张白底卡片确认。

角色 id 写在名字下面，例如三月七下面是 `sanyueqi`。朗读接口的 `character_name` 用这个 id，不用卡片上的名字。改名只改显示的名字，不改 id。

右下角加号和菜单里的「导入角色模型」都是先选一个 zip。选好后弹出导入页，不是只填一个名字。上面是文件名和大小，可以重选。角色 ID 从包里读出，不能改。显示名称预先填好：这个角色已经导入过，就用现在的名字，否则用包里的名称。可以改。留空就用角色 ID。包里如果有 wav、mp3 这类参考音频，写出文件名和时长，确认导入前可以试听。确认后才写入。主屏下拉菜单显示的就是这个名字。列表里之后也可以改名。同一个角色再导入一次，只替换模型；这次填写的名字会记下来。

一个角色包里是四个声学模型和参考音色，没有要朗读的例句，也没有韵律模型。试听用这个角色读它自己的参考句。菲比是「在此之前，请您务必继续享受旅居拉古那的时光。」三月七是「倒是不忙，可他不喜欢聊天」。

删除只删这个角色。韵律包还在。删掉的如果是主屏当前角色，主屏回到「未选择角色」。

## 服务

这一页和角色管理同级，底色也一样。顶栏左边是三横线，标题「服务管理」，右边点一下会展开日志并滚到那一栏。只管理本机的朗读接口。

顶上是状态和开关。未开启时按钮是「开启」，开启后状态变成「已开启」，按钮变成「关闭」。「已开启」下面一行是钟的图标、「运行时间：」和 `hh:mm:ss`。从接口真正打开算起，改端口接着计，关掉再开从零开始。没有调用次数或延迟。

「网络与端口」写出本机地址 `http://127.0.0.1:端口/tts`，每条地址可以单独复制。端口默认 8001，旁边可以改，离开输入框就会记住。

- 本机地址是 `http://127.0.0.1:端口/tts`，给同一台手机上的软件用。
- 局域网地址是手机当前的 IPv4，给同一网络里的软件用。没有连上局域网时不显示这一行。
- 端口默认 8001，页面上可以直接改。范围是 1 到 65535，改完会记住。接口开着的时候改端口，会先停掉原来的端口，再在新端口打开，地址跟着变。
- 页面底部是日志，可以复制。最新的一行在最上面。这一栏默认折起，点「日志」展开，标题和「复制日志」一直在。每次请求记下角色、是否拆句、每一段的合成耗时和音频时长。这一段的合成时间比上一段音频更长时，会写「播放会空等」。请求前和请求后各有一行机器统计：整机 CPU、本进程 CPU（100% 是占满一个核）、本进程内存、整机可用内存，以及电池温度。读得到机身或 CPU 温区时一并写上，并写系统热状态。同一份日志也在 logcat 的 `GenieTts` 标签里。
- 下面列出已导入角色的 id，例如 `feibi`、`sanyueqi`。请求里的 `character_name` 用这个 id，不用主屏上起的名字。还没有角色时，这里写「还没有。先在角色管理里导入」。

开启之后，通知栏留着「朗读接口开着」。切到别的应用、锁屏，接口仍可调用。点通知回到这一页。第一次开启会请求通知权限。通知没打开时，页面上写「通知没打开，系统可能会把接口收掉」。在系统设置里强制停止，或者重启手机，接口就停了，需要再点一次开启。从最近任务划掉应用时，部分手机会把接口一起停掉。

接口是 `POST /tts`。请求体是 JSON：

| 字段 | 说明 |
|------|------|
| `character_name` | 角色 id，大小写不敏感 |
| `text` | 要读的中文，不能是空的 |
| `split_sentence` | 不传或 `false`：整段合成一次。`true`：按主屏同一套规则拆句 |

空文本返回 400，角色不存在返回 404，模型加载失败返回 503。响应是 `audio/wav`，16 位单声道，采样率用角色包里的，正式角色是 32000。一句算完就把这句的 PCM 写进同一个响应。客户端断开后，当前这句在解码步之间停，后面的句子不再算。

语速固定 1.00，不跟主屏上的语速。没装韵律包时仍然返回声音，停顿和重音弱一些，接口不弹告警。同一时间只合成一路。主屏正在合成时，接口会等它结束。

## 韵律模型

韵律模型单独成一页，和角色管理同级。它不是角色，不能被选成说话人。所有中文角色共用这一份。

页面底色和角色管理一样。顶栏左边是三横线，标题，以及「已就绪」或「未安装」。

卡片上是这份文件的真实信息：文件名 `model_fp16.onnx`、占用空间、应用私有目录里的路径（可以复制）、上次写入时间。路径不在外部存储。没有版本号、校验值和镜像切换。

操作有三块。从 GitHub 下载，地址仍是下面的 `prosody.zip`，大约 571 MB。下载时在「已下载」下面有一条进度条，中断后再点会从已下载的部分继续。已经装好时，这个按钮写成「已安装」；再点会先确认，确认后会删掉本地这份再下载。从本地文件导入，可以选这个 zip，也可以直接选 `model_fp16.onnx`。文件已经在时可以删除，先弹出和角色删除一样的浅色确认。删掉后停顿和重音会弱一些，已导入的角色还在。关于里不再写文件大小。

模型文件大小必须是 599,034,176 字节。对不上就视为没装好。再次导入会替换原来的那一份。

韵律包和角色包打在同一次 GitHub release 里。文件名固定是 `prosody.zip`，根目录只有 `manifest.json` 和 `model_fp16.onnx`。`0.0.12` 没有改韵律包，应用里的下载地址仍是：

https://github.com/lostprobe99/Genie-TTS/releases/download/app-0.0.3/prosody.zip

不使用 `releases/latest`，也不使用演示程序的 `android-*` 标签。角色包在 `app-0.0.3` 里是 `feibi.zip` 和 `sanyueqi.zip`。用 `android/tools/pack_android_prosody.py` 从那份 599,034,176 字节的模型打出 `prosody.zip`。

删除只去掉韵律包，已导入的角色还在。删掉角色，韵律包还在。

没装韵律模型也允许合成。点合成或试听时，如果韵律包不在，先弹出告警，先不开始合成。

> 还没有韵律模型
> 可以朗读，但停顿和重音会弱一些。
> 继续合成　　去添加

点「继续合成」，这一次合成照常进行，后面的句子不再重复弹窗。这一轮里，每一句的韵律和参考句的韵律都用全零。声音还在，音色仍来自这个角色的参考录音。点「去添加」，打开韵律模型这一页，这次不合成。

下次再点合成，如果还是没装，告警再出现一次。这不记成失败。试听用同样的告警，按钮是「继续试听」和「去添加」。

装了以后，合成前不告警。每一句用韵律模型算自己的停顿和重音。参考句的韵律按角色包里的原文算一次，同一轮合成里一直复用。

韵律模型已经安装，但参考音素和角色包里的原文对不上时，不合成这一次，并提示重新导入这个角色。这和没装韵律包是两件事。

## 关于

关于单独成一页，底色和角色管理一样。顶栏是返回和标题。版式跟着原型：顶上是标志、GenieTTS、版本胶囊和一句标语，下面三列是 cpu架构 ARM64-v8a、这台手机的 Android 版本、ONNX v1.22.0。

「这台手机」写机型、当前角色、安装时间。安装时间是这台手机装上或更新这个包的时间。

「版本与开源信息」用图标行写软件版本、构建时间、包名，以及仓库 `https://github.com/lostprobe99/Genie-TTS`。构建时间是打这个安装包时的时间。可以复制。仓库右边是指向右上角的箭头，点它打开仓库。许可胶囊写 MIT。

「技术架构与引擎」三行：本机 ONNX Runtime、中文韵律、朗读接口 `POST /tts`。没有 WebSocket。

「致谢与隐私」写合成不把文字和声音传到应用自己的服务器。接口开着时，同一台手机或同一个局域网里的软件可以来要声音。从 GitHub 下载韵律包时会联网。致谢只写 ONNX Runtime 和角色包里的 VITS。页脚是 MIT，版权 2025 High_Logic。

没有检查更新，也不写「已是最新」「稳定版」、延迟、Apache 或另一套仓库地址。

## 第一次使用

1. 打开应用，主屏角色处是「未选择角色」。
2. 打开抽屉，进入角色管理，从本机文件导入一个角色并起名。
3. 回到主屏，在下拉菜单里选中它，输入文字，点合成。
4. 没装韵律包时会看到告警，继续就能出声。合成完成后，播放键可用。
5. 想要正常的停顿和重音，再从抽屉进入韵律模型，下载或导入。
